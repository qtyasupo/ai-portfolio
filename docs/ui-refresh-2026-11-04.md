## 方向与改动

面向寻找 AI 作品、教程和工具的创作者，采用纸色、墨绿与朱红的杂志式视觉。主标题使用衬线字体，配合雷达刻度插画、真实收录数量、平台分栏与深色日报入口。保留 Next/React 及 CSS 实现，不增加前端运行依赖或远程字体服务。字体使用明确命名的本机字体族；跨设备的具体字形可能不同。

- `app/editorial.css`：独立的视觉层与响应式规则，经 `app/layout.tsx` 在基础样式之后加载；移动端显示平台资料数量，保留减少动态效果的系统偏好。
- `lib/presentation.ts`：从来源文字提取阅读用短标题，省略标签、网址及重复摘要；逗号结尾的首行会结合第二行。仅影响卡片呈现，完整标题、证据、源链接和导出数据保持原样。该摘录不是模型改写或事实核验。
- `components/RadarApp.tsx`：显示当前筛选条件、统一清除入口、实时结果数量；收藏无匹配时不再误报“还没有收藏”。为筛选、收藏和导航增加可访问状态。
- 弹窗锁定背景滚动、限制键盘焦点在内部，Escape 关闭并返回原触发按钮。手机导航有遮罩、关闭按钮、焦点循环和滚动锁，切回桌面自动收起。收藏数据异常或存储不可用时不让页面崩溃。

本轮未更改采集规则、数据库、平台会话或公开快照；预览展示18条既有公开资料，更新时间仍为2026-11-02。没有新增采集，不能描述为11月4日实时热点。

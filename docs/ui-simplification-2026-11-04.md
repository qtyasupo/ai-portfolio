# 2026-11-04 · 简化首页入口

用户审阅本地 `519fe4c` 后反馈入口不简洁、不直观、杂乱。本轮以减少同时可见的入口为目标，替代第一轮杂志式首页，仍仅保留本地。

## 最终结构

- 顶部只有站名、浏览资料、我的收藏、创作日报和更多；更多中保留热点、采集工作台、关于、刷新和导出。
- 首页单栏：简短说明 → 搜索框 → 五个平台选项（含全部）→ 资料列表。
- 类别、发布时间、历史归档合并到默认折叠的“筛选”中，有明确完成按钮；支持点击外部和Escape收起。选中条件可见并可清除。
- 推荐与最新改成一个排序选择。最新排序对所有合格收录资料排序；资料范围另行筛选，避免切换排序时隐式丢失历史内容。
- 移除左右栏、雷达插画、重复分类导航、首页话题索引、独立日报宣传卡、卡片装饰图标/标签/规则分数。规则分数仍可在详情查看。
- 卡片保留来源、作者、发布时间、类别、阅读摘录与平台互动；收藏和原文入口带文字。管理与核验功能仍保留在工作台。

`components/RadarApp.tsx` 与 `app/editorial.css` 是本轮实现入口。没有新增前端依赖或请求外部服务。没有更改采集、数据主库、公开快照或平台会话；快照仍为11月2日的18条资料。

## 验证

- 17项现有测试、类型检查、最终生产构建通过。
- Chrome桌面：clientWidth/scrollWidth均1905；首条资料的卡片起点在首屏约403px处，页面为单栏。控制台无warn/error。
- 抖音筛选5条，AI短剧7条，搜索Claude6条；清除恢复18条。最新发布排序仍显示18条。近7天筛选显示12条。
- 收藏、我的收藏计数、取消收藏、日报与更多中的工作台可用。
- Chrome375px视口无横向溢出；筛选面板宽240px且完整位于视口内，点击完成/按Escape可收起。手机首屏能看到首条资料。
- 详情仍锁定背景与键盘焦点；Escape返回原卡片。关于弹窗初次关闭后焦点落到body，已修正并复验返回“更多”summary。

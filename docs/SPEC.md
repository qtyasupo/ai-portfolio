# Yasupo AI 创作雷达 · 重写规格

目标：将现有 ai-portfolio 网站重写为中文 AI 创作情报站，沿用 www.yasupo-hub.cn。原站基线 00102433f83e70ea3f4fea701ee39eb364f7b95f，所有改动先在 rewrite/creator-radar 分支、本机和预览验证。

## 必须可用

- 四个平台：抖音、小红书、YouTube、X。保留原文链接、作者、发布时间、采集时间、查询词与可见指标。未获得内容或日期时明确留空；不把链接列表当作已读正文，不把简介当字幕。
- AI/AIGC、AI 短剧、AI 视频、代码动画、Claude 代码动画、工具教程分类；关键词搜索、平台/分类/时间筛选、精选/最新切换、本机收藏、来源详情。
- 与 AIHOT 对齐的工作流：采集 → URL 去重 → 相关性筛选 → 质量评分 → 事件候选聚合 → 热点 → 日报。未配置模型时使用明确标注的规则筛选；不声称双模型评分已运行。
- 未知/估算日期不进入公开资讯流；首次导入、历史回灌归档。可信日期的旧文不进入今日。平台互动与跨信源热度分开。
- 热度只统计 48 小时内独立发布方最新证据，24 小时半衰期；至少两发布方、一条可展示内容才进热点榜。没有六小时前快照时不显示虚假的增长百分比。
- 数据持久化；去重更新保留历史观察；日报绑定日期，统计只基于该日合格样本；相同标题但事件不同不强行合并。
- 采集工作台：平台状态、查询词管理、真实运行日志、JSON 导入、立即采集（本机）、导出。遇到登录/验证/限流停止该渠道，保留其他平台结果。
- 本机浏览器会话留在本机。Vercel 使用远程 libSQL 数据库时持续读写；未配置数据库时展示经过导出的只读数据快照，并在界面明确标记，不把临时文件当持久数据库。
- 管理写入仅本机同源请求，或持有服务端管理令牌；Vercel 无远程数据库或令牌时写入关闭。令牌/API key 不进入客户端、导出数据或日志。

## 交付与验证

核心验证面为 Radar 的 ingest/read（去重、隔离、观察历史、热度、日报）和 HTTP 写入口（认证、格式校验）。检查构建与 TypeScript、实际跑平台采集、浏览器检查主要操作与窄屏。成功、失败与尚未配置的能力分别记录。不开通付费服务，不将用户浏览器凭据上传云端。预览可部署，生产域名切换前交付可审阅结果。

不承诺全平台全量或无限历史，不自动下载媒体，不自动发帖/点赞/评论。不复用 AIHOT 名称、Logo 或未经许可的全文；参考流程的简化之处单独列明。
